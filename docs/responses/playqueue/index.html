Errata: In the original spec, current is required to be an int. However, as child ids are strings, this is updated to note that the id should be a string to be consistent.

FieldTypeReq.OpenS.Details
currentstringNo*ID of currently playing track
positionlongNoPosition in milliseconds of currently playing track
usernamestringYesThe user this queue belongs to
changedstringYesDate modified [ISO 8601]
changedBystringYesName of client app
entryArray of ChildNoThe list of songs in the queue
OpenSubsonic

* If entry exists and is non-empty, OpenSubsonic servers must ensure that current exists and is a valid id in the list of songs.

If position is omitted, clients should treat the position as 0.
